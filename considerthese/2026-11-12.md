## 2. Suggestions (new; none repeat 11-05 → 11-11)

1. **Budget `.ufo/waves/`, which is 91% of the repo.** Of 30,383 tracked files on master, 27,629 sit under `.ufo/waves/`, against 1,682 in `corpus/evidence`, 174 lessons and 81 knowledge entries. The repo is about 84 MB. Wave scratch is drowning the admitted corpus, which slows every clone and fresh read and makes "what is evidence" hard to see. Proposal: per closed round, pack its wave directory into one archive with a sha256 manifest committed in its place (or move it to a release asset), keep only the manifest and the admitted evidence on master, and add a grader check that fails when tracked `.ufo/waves/` files exceed a set budget. This is the same unadmitted-work-on-master hazard as the root strays, at a far larger scale.

2. **Pin golden values for the hand-rolled statistics.** `grader.py` (5,737 lines) computes its verdict p-values with its own stdlib math: `betai` (line 915, a Numerical Recipes continued fraction), `t_two_sided_p` (928), `t_crit` (933, by bisection over `t_two_sided_p`), `exact_sign_p` (949) and `exact_mcnemar_p` (958). Nothing in the file checks them against reference values. They feed the r11 verdict (line 1254, 1293) and the paired comparisons at 1796 and 1813. `--selftest` mutates artifacts; it does not test the math. Proposal: add a fixed table of about 20 reference points (t, df, p and b, c, p) computed once with scipy and committed as data, including edge cases (df=1, very large t, b=c=0, x near 0 or 1 in `betai`), and have the selftest require agreement to 1e-9. A silent numeric bug here would flip "significant" verdicts while every structural check stays green.

3. **Split `grader.py` into frozen per-round modules.** The file has 7 `grade_rNN`/`check_rNN` entry points and still carries a manual merge instruction at line 1727 ("L1: paste from here to the `fixture selftest` marker into grader.py"), which means round graders were integrated by copy-paste. Any later edit to shared helpers such as `_replay_graded` or `_build_meta` can change how an old round grades without anyone touching that round. Proposal: move each round grader to `graders/rNN.py`, record each module's sha256 in the round's admission record, and have the top-level runner refuse to grade a closed round if its module hash drifted. Shared helpers get their own hash. This makes "PASS 733/0" mean that the same code that admitted each round still passes it.
