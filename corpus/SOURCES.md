- contamination audit — S001 → S002 → S004 → S005 → S006 → S022: map the detection space first, then the concealment failure mode, then resistant design, then two lab self-audits showing what detection failure costs in practice, then a live refresh mechanism.
- judge calibration — S012 → S009 → S010 → S011: canonical bias catalogue, then the newer scoring-prompt and rubric-order biases, then the correction method that prices sensitivity/specificity and calibrates intervals.
- agentic evidence — S013 → S014 → S020 → S021 → S005: the horizon measure and its live data, then task-level benchmarks (terminal, multi-app tool use), then a task-quality audit showing benchmark claims need their own audit.
- statistical reporting — S015 → S016 → S017 → S018 → S019: the canonical error-bar recipe, run-level nondeterminism, resampling model plus data variation, paired resolution diagnostics, then adaptive sampling that still preserves coverage.
- saturation and lifecycle — S008 → S007 → S005 → S001: construct validity first (is the benchmark measuring its construct), then the saturation index, then a real retirement decision, then the contamination pressure that shortens lifetimes.
