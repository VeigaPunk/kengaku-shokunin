## Findings and non-obvious move

**C2's advertised universe is self-expanding.** The frozen counter scans `SCORECARD.md`, `SKILL.md`, `LOG.md`, `corpus/README.md`, and `corpus/knowledge/*.md` for `python3 <path>` commands; its regex accepts both new depth-1 files `plans/round52_c1_grader_audit.py` and `plans/round52_c2_registry.py`, and both files already exist at the base tip. They are not currently advertised, so baseline is `ADVERTISED total=72`, `MISSING 28`. A scratch-copy simulation adding the two round-52 counting commands to `SCORECARD.md` yielded `ADVERTISED total=74`, `MISSING 2` for the round-52 scripts. Thus **MISSING 0 requires registry rows for the 28 frozen missing instruments plus both new round-52 counters: 30 additions in total**, unless the after-run's scanned text omits the new commands. The round's own instrument citations in SCORECARD/LOG/README/knowledge are the likely trigger; adding them to README/knowledge is independently sufficient. If any `corpus/evidence/round52/<name>.py` is also advertised with `python3`, it matches the counter's evidence-path pattern and needs a registry row too. (Captured files under `round52/graders/...` are deeper than that regex.)

**C1's pre-read set is not being extracted from the current corpus entries.** The frozen counter's `lane_read_tasks()` scans `corpus/knowledge/tb2-*-grader.md`, then searches for `task \`NAME\`` or `NAME task`. The 12 existing files use H1s of the form `... task grader, read and executed: \`NAME\``, which does not match the first form; the fallback instead extracts `this` from 10 entries and `0` from 2. Measured set: `['0', 'this']`, not the 12 task names. Consequently, a confirmation for an already-hand-read task such as `protein-assembly` would count as `CONFIRMED new` in the frozen counter. The corpus README's 12 task-specific knowledge rows are the auditable manual list; the falsify/review wave should compare confirmation task names against that list rather than treating the counter's `new` result as proof of novelty. Do not change the frozen counter or claims in this round. Also avoid naming the new knowledge entry with the glob suffix `tb2-*-grader.md`: that makes it an input to this extraction and can alter the measured set. The candidate `tb2-grader-vacuity-triage.md` does not match that glob; `tb2-vacuity-triage-grader.md` does.
