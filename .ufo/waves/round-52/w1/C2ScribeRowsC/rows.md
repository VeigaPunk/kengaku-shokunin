   inside its pinned-values cell so no reader takes a historical counter for a live clean gate.
   The other four rows are green on the lane as measured today (`defects=0`, exit 0 each).
2. **Self-test cells are written to survive `plans/round52_c2_registry.py`'s
   `selftest_unbacked` rule**, which flags a cell naming exactly one `plans/*.py` script and a
   `--flag` that script does not accept. The four real self-tests name `--selftest`, which is in
   each script's argparse block; the round-35 cell names no script path at all, because that
   counter genuinely has no self-test and naming it there would be a false accusation of the same
   kind the rule exists to catch.
3. **`kind` is `gate` for all five** because each exits non-zero on a defect. None of them is a
   probe in the registry's sense (a probe prints its mismatches on a summary line and still exits
   0); the four counters print `checks=N defects=M` and exit 1 on any defect, and the round-35
   counter adds `PREDICATE C1 pass|fail`.
4. No cell contains a `|` character, and each row has exactly eight cells, so `parse_rows` in the
   frozen counter reads them as complete rows.
