## Round76 criterion draft — routed means registered, closed means re-derived

**D1 (draft label, not a new Q-number allocation).** A newest-closure routed finding has an identified row in `corpus/routed-findings.jsonl`, a status, a meaningful committed-path/literal check, and a separately stored `close_commit` if closed. A human-readable `close` sentence or `status: closed` is not discharge evidence: re-derive the finding's value and require its closing commit to resolve and be an ancestor of the measured branch tip. `git merge-base --is-ancestor` status 0 means ancestor, 1 means not-ancestor, and another failure is unresolved/error; do not conflate the latter two. No check passes merely because there are no registered rows.

For **R75-D1**, the report must be committed only after the final lane commit it cites; correction of filed bytes is a new dated erratum naming the superseded text, never a rewrite. R75-D7 extends that same append-only correction discipline to filed lessons. A policy sentence is not evidence that the final reporting order occurred; history must witness it. This draft does not assert that round-76 report order has already been exercised.
