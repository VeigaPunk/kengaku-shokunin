## 6. Live-vs-archive table and the delta

| run | lane state | fleet state | defects | exit | red checks |
|-----|-----------|-------------|---------|------|------------|
| A | live repaired (HEAD 7895588) | live repaired | 0 | 0 | — |
| B | `git archive f0b20aea`, no index | live repaired | **4** | 1 | N1(idx), N2, N5, N6 |
| C | archive `--selftest` | n/a (fixtures) | 14 cases, 0 failed | 0 | — |
| D | reconstructed pre-repair (real index) | pre-erratum | **6** | 1 | N1..N6 — byte-identical to control |
| E | archive, no index | pre-erratum | 6 | 1 | N1(idx reason), N2..N6 |
| G | live repaired | pre-erratum | 2 | 1 | N3, N4 |
| H | `git archive c227e486`, no index | live repaired | 4 | 1 | N1(idx), N2, N5, N6 |

Delta B vs the committed control = 2 checks (N3, N4) plus N1's *reason string*. Three
distinct causes, none of them a lane repair inside the archive:

1. N3/N4 are FLEET-COUPLED BY CONSTRUCTION. In plans/round33_defects.py:40,
   `FLEET = Path("/home/vgpnk/Projects/shokunin")` is an absolute constant, and
   check_n3/check_n4 default to `R31_REPORT`/`R32_REPORT` under it. `--lane` does not
   redirect them. The fleet repo already carries the L1's erratum commit 3d3ca566, so on
   any lane tree — including the freeze archive — N3/N4 read repaired report bytes and go
   green. RUN G proves the coupling is one-directional and exact: holding the lane at the
   repaired HEAD and swapping ONLY the fleet bytes turns exactly N3 and N4 red (2 defects),
   leaving N1/N2/N5/N6 green.
   The counter's own selftest docstring states the hazard: "N3/N4 read absolute fleet paths
   by default, which would couple the selftest to the live repair state." The mitigation was
   applied to the selftest only; the `--lane` path remains coupled.
2. N1's redness on B/E is an ARCHIVE ARTIFACT, not evidence. `git archive` exports no
   index, so `git ls-files` fails and check_n1 reports the git error instead of an untracked
   set. The control's actual N1 finding (84 untracked paths) is reproduced only once an
   index exists — RUN D, whose N1 message equals the control's character-for-character,
   sorted example filenames included.
3. N2/N5/N6 are pure lane-content checks and behave exactly as the claim says: red on
   f0b20aea (RUN B, RUN D, RUN E), green on the repaired HEAD (RUN A, RUN G).

Consequence for C2: the committed control defects-before.txt is a valid, byte-reproducible
record of the pre-repair tree, but it is reproducible only as a JOINT state
(lane@f0b20aea + fleet@pre-3d3ca566). Once the L1 appends the N3/N4 errata, the archive
re-run cannot show 6 again, and a reviewer who runs only `--lane <archive>` will see 4 and
must not read that as a failed reproduction or as a lane-side regression. Conditional on
that joint state, the frozen predicate holds in both directions:
repaired+repaired -> checks=6 defects=0 exit 0 (RUN A);
pre-repair+pre-erratum -> checks=6 defects=6 exit 1 (RUN D).
