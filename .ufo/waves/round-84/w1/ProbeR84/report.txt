## Instrument

`round84_gcode_probe.py --lane DIR --work DIR`:

1. Reads DIR/corpus/evidence/round52/graders/gcode-to-text/tests/test_outputs.py and requires
   sha256 == 6b049dc6…701a6 (exit 2 `SETUP wrong-subject` otherwise), and requires the two
   test functions, in definition order, to be exactly `test_hello_file_exists`,
   `test_hello_file_content`.
2. Reads the case table: DIR/plans/round84-cases.json when present, else the table shipped
   beside the tool (which must then be byte-identical to the frozen sha 5b86f8d7…2cb5).
   Member, case count, id order and every predicted vector are checked against the frozen
   claim (exit 2 `SETUP wrong-table …` otherwise). Staged content is table data.
3. Per case: fresh directory under --work, `/app/out.txt` written with the row's content
   (file omitted when content is null), then the captured module is executed unmodified in
   bubblewrap: `--unshare-all` (no network), `/usr` and `/etc` read-only, case dir bound as
   `/app`, the checked capture bytes snapshotted and bound read-only at `/tests/test_outputs.py`,
   `--clearenv` + C.UTF-8, `python3 -I -B`. A harness parses the module AST, runs each test
   separately, and classifies AssertionError/FileNotFoundError = F, normal return = P, any
   other exception = D.
4. A D verdict is a setup defect: `SETUP case=<id> unexpected-exception=…`,
   `PREDICATE R84-PROBE could-not-evaluate`, exit 2. Otherwise prints the 12-field stamp in
   round-83 order (`MEMBER, SUBJECT_CAPTURE, SUBJECT_SHA, CASE_TABLE_SHA, TOOL, TOOL_SHA,
   HOST_PYTHON, HOST_OPENSSL, LANE_TIP, WORKTREE, COMMAND, EXIT`) then
   `OBSERVATIONS_BEGIN` / 8 `CASE <id> predicted=<v> observed=<v>` / `cases=8 mismatches=N` /
   `PREDICATE R84-PROBE pass|fail` / `OBSERVATIONS_END`. Exit 0 pass, 1 mismatch, 2
   could-not-evaluate. `COMMAND` is the reconstructed canonical argv
   (`python3 <lane-relative tool> --lane . --work <work>`); it is not executed from the receipt.
5. `--selftest` runs 13 checks: frozen table bytes/vectors, no host `/app` creation, invocation
   exit+header, stamp order, stamp values (subject/table/tool shas, lane tip, worktree, command,
   exit), observation block, wrong-subject → 2, wrong-predicted vector → 2, content drift → 1,
   and the three classification/continuation fixtures (AssertionError, FileNotFoundError,
