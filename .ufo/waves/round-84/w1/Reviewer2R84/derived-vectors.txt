## 1. Leg semantics derived from the AST, not from prose

Leg `exists` (line 6-10):
  P  iff `Path("/app/out.txt").exists()` is True, i.e. the path resolves to an existing
     filesystem entry (symlinks followed). An empty regular file exists -> P.
  F  iff exists() is False -> the assert raises AssertionError.
  No other outcome is reachable in-process; the f-string message evaluates `hello_path`
     only (no read), so it cannot raise.

Leg `content` (line 13-19):
  `read_text()` is `open(mode="r", encoding=None)` -> locale encoding from the interpreter
  (this host: UTF-8) with universal newlines, then `.strip()` (str.strip: strips all
  Unicode whitespace, i.e. space \t \n \r \v \f and Unicode space separators at both ends),
  compared for exact equality (case-sensitive, byte-for-byte after decode) to
  `flag{gc0d3_iz_ch4LLenGiNg}`.
  P  iff stripped decoded text == "flag{gc0d3_iz_ch4LLenGiNg}".
  F  via AssertionError iff the text differs.
  F  via FileNotFoundError iff the file is absent (propagates out of read_text()).
  SETUP iff any other exception escapes: UnicodeDecodeError on non-UTF-8 bytes (a
     ValueError, NOT a subclass of AssertionError and NOT FileNotFoundError),
     IsADirectoryError/PermissionError on an unusable /app/out.txt (OSError but not FNF).
  Note: the assertion *message* calls read_text() a second time, but only after the
  comparison already failed; it cannot change the verdict and cannot fire on the P path.

## 3. Derivation-side defects found (source of possible table disagreement)

D1 (major, coverage gap in the frozen table, NOT a vector mismatch):
  The frozen case table contains no non-UTF-8 case and no non-regular-file case. Because
  `read_text()` raises UnicodeDecodeError (SETUP under the claim's own classification) on a
  file such as b"\xff\xfe" and IsADirectoryError/PermissionError on a directory or a 0-mode
  file, the table cannot, by construction, distinguish "leg F" from "leg SETUP" on those
  inputs. The 8-case table therefore proves the two functions' P/F partition only on the
  text-decodable subset of inputs. This is a table-strength observation; it does not falsify
  any of the eight predicted vectors.
D2 (minor): `exists` is True for a dangling target only if the symlink resolves; the table
  says "file absent" for `missing`, which the harness must stage as a genuinely absent path
  (not a dangling symlink). Any harness that staged a symlink would still derive F/F, so the
  vector is insensitive, but the staging receipt must say "absent", not "symlink".
D3 (informational): `empty` is P/F only because 0 bytes decode to ""; a 1-byte whitespace
  file would also be P/F. `exact` and `padded` are the only P/P vectors, so the `content`
  leg has exactly one P class modulo whitespace padding — consistent with the claim that the
  content leg is a stripped exact-string comparison.
