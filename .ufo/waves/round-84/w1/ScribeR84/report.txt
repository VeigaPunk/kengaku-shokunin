FINDINGS AND MEASUREMENTS (read-only; every number below was measured here, none is from a receipt)

F1. The Q13 checker resolves only flat `.md` report paths, so the L1's correction to `.md` paths is
    necessary but not sufficient on its own. plans/gate_timing_check.py's FULL_REPORT_RE matches
    `.ufo/waves/round-(?P<round>\d+)/(?P<wave>[A-Za-z0-9][A-Za-z0-9_-]*)/(?P<name>[A-Za-z0-9][A-Za-z0-9_.-]*\.md)`,
    i.e. exactly five path components ending in `.md`. Measured against `plans/gate_timing_check.py`
    imported as a module in a scratch fixture: a cell citing `.ufo/waves/round-84/w1/ReviewerR84/report.md`
    extracts zero citations (`cited seat-report paths: none`) because that path has six components;
    a cell citing `.ufo/waves/round-84/w1/ReviewerR84.md` extracts the citation but is then rejected,
    because `is_second_wave()` accepts only a directory named `falsify` or matching `wave[-_ ]?0*2`, and
    `w1` is neither. In a scratch fixture whose second-wave directory was named `falsify` and held a
    `swarm-registry.json` naming the seat with role `reviewer`, the same checker exits 0 on the
    successor-admission row (PASS, `existing returned second-seat report(s)` named). The lesson draft
    therefore cites the L1's paths and adds a gate-timing note; the installer must place the two reports
    where the committed checker resolves them, or amend the checker's wave rule. This is a layout
    constraint on the installer, not a change to the frozen claims doc.

F2. The checker also requires the entry to carry a line-start `writer:` field, and rejects a report whose
    own `writer:`/`author:` declaration equals the candidate writer. Measured in the same fixture:
    removing the entry's `writer:` line flips the admit to FAIL ("candidate has no committed writer: field;
    self-review cannot be excluded"), and a report containing `writer: KengakuR84` is rejected
    ("report writer/author declaration equals candidate writer"). The lesson draft therefore states that
    this round's repair adds `writer: KengakuR84` at entry line 4 and asks the re-read seats to declare
    the candidate writer in a field that is not a bare `writer:` line. The draft does not assert that any
    reviewer report does so.

F3. R82-F1's blind shape is wider than the routed row's four rows. The routed row names S260, S261, S265
    and S266. A read-only pass over the same bytes with the lane's own parser (plans/anchor_line_check.py
    imported as a module, corpus/SOURCES.md parsed by its parse_rows) finds 61 of the 262 rows carry a quote
    character in the anchor cell that its QUOTE_RE does not parse, and they include the round-83 rows
    S267-S270, whose anchors place the quoted text after a `quote` word or inside a backtick rather than
    directly after `:NN`. The lane's own check still exits 0 with `ANCHORLINE rows=262 cited=72 ... live=0
    cells=0` — green because blind. The SCORECARD planned item says so and requires the repaired
    counter's red-before to be measured on the widened set.
