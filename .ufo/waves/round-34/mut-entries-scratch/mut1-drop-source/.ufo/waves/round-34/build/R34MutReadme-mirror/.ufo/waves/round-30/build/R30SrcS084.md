### Word-count convention

Chinese has no inter-word spaces. Counts below are **whitespace-delimited tokens of the verbatim run** (`str.split()` semantics), so a whole Chinese clause counts as one token and each Latin-script/ASCII item (a dataset name, a version-like token) is its own token. Every count is the *measured* token count of the quoted bytes, not a morpheme count — this makes the <=25-word ceiling trivially satisfied for CJK-only quotes and means the ceiling binds only through Latin/mixed insertions. Stated explicitly because the same convention must be used by the C3 gate.
