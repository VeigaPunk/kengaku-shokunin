## 11. Oracle domain boundary (hand cases, synthetic, in-memory)

- Frozen-profile values are JSON-safe, so raw-text replacement equals decoded-leaf
  rewriting (verified exhaustively, `True`). Outside that domain the two diverge.
- Value containing `"` → projected text fails `json.loads` with `JSONDecodeError`

- Value containing a literal backslash → `JSONDecodeError` invalid escape.
- Value containing escaped slashes `http:\/\/x` parses to decoded `http://x`, i.e. the
  inserted text is not the decoded value (escape-representation divergence).
- A token inside a content field would be replaced as well (hand witness
  `{"intent": "go to __GITLAB__ now"}` → content changed); item 389 itself has no
