  counterexample is singular, not merely rare; a tree-wide `grep` cannot be the check, axis H is
  per-task.

  `count-dataset-tokens` (`= 30` / `= 120`), `reshard-c4-data` (`= 30` / `= 60`), `train-fasttext`

  Because both fields in a task are the same type, a float-only parser, or one comparing as strings,
  misfires on the **pair**, not on isolated lines; parse as number.

  (mode 30.0/60.0, 13 each); junior 60.0–2400.0 (mode 120.0, 13). Numeric, per-task, plausible —

Reproducibility hazards, measured per host on 2026-10-25 (`curl` **without** `-L`, `%{num_redirects}`):

- `raw.githubusercontent.com/laude-institute/terminal-bench-2/<sha>/…` → **200, redirects=0, 973 B**.
  `codeload.github.com/laude-institute/terminal-bench-2/tar.gz/<sha>` → **200, redirects=0,
  40357259 B**. Both follow the old owner name fine; neither needs `-L`.
- `api.github.com/repos/laude-institute/terminal-bench-2/git/trees/<sha>` → **301** on the first
  fetch of this round, body **264 B** (`{"message": "Moved Permanently", "url":
  "https://api.github.com/repositories/1063848495/git/trees/…"}`), i.e. the API path is the one that
  the repo rename breaks; only the numeric-id URL (`/repositories/1063848495/…`) or `-L` resolves it.
- That same API path is **rate-limited to 60 requests/hour unauthenticated**, and this round exhausted

  (= **2026-10-25 04:38:43 −03**).

Operational consequence for the S079 Gate line: quote **and** re-count from the raw/codeload channels
(no redirect, no quota), and treat the API tree listing as a listing-only convenience that needs
`-L` plus a token — a Gate that re-runs tree listings on the bare API will start failing at request 61
with a body that is not the source at all.
