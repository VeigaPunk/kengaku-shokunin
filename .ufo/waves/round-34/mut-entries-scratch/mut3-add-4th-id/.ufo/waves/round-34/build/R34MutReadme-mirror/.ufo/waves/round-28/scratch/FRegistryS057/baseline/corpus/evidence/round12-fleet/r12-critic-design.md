## Verdict-rule and statistical falsification

R1's three branches are exhaustive for finite p and a binary direction: established when p<.05 and L is increasing, directional when p≥.05 and all three adjacent point estimates are positive, otherwise unsupported. R2's four branches and R3–R5 are likewise ordered and exhaustive only after the neutral-sign, zero-variance, and undefined-calibration cases above are pinned. “Direction” should be explicitly defined as `L > E_L` (positive z), not left as prose.

Page's test is a defensible confirmatory choice for four ordered treatments in randomized blocks: it uses one ordered alternative and avoids three pairwise multiplicity penalties. Friedman plus post-hoc tests would discard the ordering power; repeated paired t tests would require multiplicity control. With k=4 and n=64, bounded per-block rank contributions make a normal approximation defensible, including heavy integer ties if the conditional midrank variance is used. For k=4 the per-block null variance can be computed exactly as `(5/3) * Σ_j (rank_j-2.5)^2`, then summed across blocks; this is preferable to an unspecified generic tie correction. An exact conditional convolution is a possible robustness check, not a requirement for the preregistered normal test.

The error contingency's listwise deletion by pid (`probe_plan_r12.md:2.3`) preserves complete four-arm blocks for Page and complete paired units for the paired tests. It can, however, unbalance the originally rotated arm-position counts; report realized position counts after deletion. E6 must separately specify whether excluded pids' predictions are removed (recommended) rather than scored as failures.

Construct checks that survived falsification: A-CKPT10 and A-MONO both have one full-state emission, while A-CKPT10 presents operations incrementally, so their contrast is a reasonable batching dissociation but does not prove that batching is the *only* mechanism. Family-2 `nwrong` is comparable within paired turns because both arms share the same per-pid target list at each turn, even when APP/DEL changes length; parse failure=`len(want)` is arm-invariant within a problem. The turn-1 full-state/ack logging quirk is shared by CKPT10 and CKPT710 (`probe_plan_r12.md:2.1`), so it does not differentially bias that pair, although it remains a measured protocol quirk.
