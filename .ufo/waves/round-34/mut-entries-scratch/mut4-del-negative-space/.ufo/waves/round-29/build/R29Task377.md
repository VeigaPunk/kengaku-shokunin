## Replacement mechanics witnesses (derived, no upstream execution)

  inside it, because later passes see the already-replaced text (`http://g.invalid/http://r.invalid/y`). No frozen

- Single pass, non-recursive: a value that itself contains its own token is not re-expanded (`__MAP__h/x`).

- No repair path: a synthetic value containing `"` makes `json.loads` raise `JSONDecodeError: Expecting ','
  delimiter` (observed at offset 6378 with that probe) — the contract is fail, not repair. Same for backslashes.
