## 2. Method (independent of production code)

1. Element spans: repeated `json.JSONDecoder.raw_decode` over the raw text yields the 812 array
   elements with exact start/end codepoint indices.
2. Occurrences: literal scan for each `__TOKEN__`; every occurrence is asserted to sit inside one JSON
   string literal (enclosing-literal scan with backslash-parity), so no token can straddle structure.
3. Occurrence → field: substitute a unique sentinel at exactly one occurrence inside the containing
   element slice, re-parse that element, and diff leaves; assert exactly one changed leaf and that
   removing the sentinel restores the original value. (Value-equality match was rejected after it
   double-counted duplicate values — an earlier draft produced 399 GITLAB occurrences against a true
   385.)
4. Projection: six `.replace` calls in the declared order over the raw TEXT, then `json.loads`, then a
   leaf walk with paths of the form `$['eval']['program_html'][0]['url']`.
5. Independent cross-checks: byte-level projection (`bytes.replace` on retained bytes), element-local
   replacement versus global projection, and per-leaf value-level replacement versus projected value.
