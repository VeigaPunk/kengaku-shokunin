## 8. Profile sensitivity — controlled configuration effect only

Of 1,435 occurrences, **697 are immediately followed by `/`** and **738 are immediately followed by
the closing quote** (whole-value token). Consequences, observed as literal string effects:

- `trailing_slash_sensitivity`: every substituted origin already ends in `/`, so each of the 697
  slash-followed occurrences produces a literal `//` seam. Projected text contains exactly **697**
  non-scheme `//` occurrences; the other 738 occurrences end at the value boundary.
- `path_prefix`: `/prefix` is inserted between the synthetic origin and the original path suffix; for
  the 738 whole-value occurrences the entire value becomes `origin/prefix`.
- `distinct_origins`: no seam anomaly (non-scheme `//` = 0).

This is a **configuration-string effect** of the three frozen synthetic profiles. It is not evidence
about URL normalization, HTTP routing, server behavior, or whether any real deployment would accept
these strings. No profile is a deployment recommendation.

- Frozen input: ordinal == `task_id` for all 812 items (ids are 0…811 in order). This is a property

- Generator uses `enumerate(data)` for the filename and never reads `task_id` (0 occurrences in

## 11. Oracle-domain boundaries and failure witnesses

All witnesses below were executed in memory; no fixture or profile was modified.

1. **Leaf-level (decoded) rewrite equals text-level projection** for the three frozen benign
   profiles: parsed objects compare equal for all 812 tasks in each profile (True ×3). Byte
   identity is a separate artifact — a decoded rewrite re-serializes and cannot reproduce the
   WIKIPEDIA-aware text digests above.
2. **Wrong scope fails, measurably.** Restricting the rewrite to URL-typed leaves
   (`start_url` + `reference_url` + `program_html.url`) leaves **62 residual token occurrences**
   (60 `must_include` + 2 annotation) and a non-equal parsed object.
3. **Quoting boundary is a real divergence, not a nuance.** With a synthetic value containing `"`
   (not a profile), text-level replacement yields text whose `json.loads` raises
   `JSONDecodeError` at char 43022 (`Expecting ',' delimiter`), while the leaf-level oracle
   succeeds. A source-faithful projector must therefore *fail* rather than repair or normalize;
   the decoded-leaf oracle is only valid inside a quote/backslash-free value domain.
4. **Order is a contract.** Injecting a later token into an earlier value
   (`GITLAB → "__MAP__hook"`) is silently consumed by the subsequent MAP pass: final `__MAP__`
   count 0, but the emitted value is corrupted. Injecting an earlier token into a later value
   (`MAP → "__GITLAB__hook"`) leaks: **133 residual `__GITLAB__`** occurrences survive into the
   output, because the GITLAB pass already ran. Same six literals, different order ⇒ different
   document. The frozen profiles trigger neither case (no profile value contains `__`, verified by
   construction and by residual counts of 0).
5. Alternative-order defect class for the production tool's wrong-order witness: a URL-only or
   wrong-order implementation is detectable by residual-occurrence count (62 and 133 above) and by
   parsed-object inequality, not by total task count — the totals stay 812 in all failing variants.
