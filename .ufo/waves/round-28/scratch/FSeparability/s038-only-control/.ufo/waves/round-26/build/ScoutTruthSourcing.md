## D1: make “previous turn truth” explicit
- For ordinary A ladders, at operation turn `t>1` use `meta.truth[t-2]` (or `meta2.truth[t-2]` for family 2); at `t=1`, use `meta.init` (family 2: `meta2.init`). `truth[turn-1]` is the current target. This uses operation turns, not the last *graded* checkpoint; e.g. a checkpoint at turn 4 still has previous truth `truth[2]` although turns 1–3 were acks. The source prompt starts with `Initial state` (`horizon.py:129-130`, `replicate.py:129-131`; r12 family-2 meta at `run_r12.py:222-230`).
- A-MONO is a single final-answer call logged as turn 1: if D1 needs an anchor, use the input `init` (no prior assistant answer); current target remains `truth[-1]`.
- r8 B is also logged turn 1, but its prior context is after seven operations: D1's **true** prior state is `meta.truth[6]`, not init. In clean cells the displayed post-op-7 state equals `truth[6]`; in corrupt cells the displayed `state_mid` is intentionally false. Use the correct meta truth as the “truth” block; document the visible corrupt state separately, and retain B's target `truth[-1]`.
- r8 C-conflict/benign/norule also have prior assistant turns despite `turn=1`: the immediately preceding truth-bearing scaffold is row 3, `rows[2]` (`horizon.py:249-261`). It is an array, not the expected final-answer dict; appending it as a final fenced block makes `extract_json_block` return a list and `grade_c` reject it. Keep this D1 case distinct (or explicitly N/A), not silently mapped to init/dict-state truth. C-MONO has no previous assistant turn or supplied initial state; D1 is N/A absent a separately defined anchor.
- Collision caveat: previous truth equals current target on 19/1948 non-C graded records (0 of the 82 operation-turn-1 ladder records); those distractors would be identical to the target and are non-discriminating for last-block extraction. Report their count alongside D1 results or stratify them. This count is per record, so repeated arms may refer to the same pid/turn.
