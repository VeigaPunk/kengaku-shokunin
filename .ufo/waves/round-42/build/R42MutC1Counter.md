## Method

1. `git clone -q --shared` the lane into `$S/lane` (`S=/fast/scratch/hyaku/kengaku-r42/R42MutC1Counter`);

2. Seven control setups, one per committed C1 control, each a scratch mirror + (where the control patches the

   `plans/battery42`, as `control-c1-witness-as-battery.txt` did), `A` attribution patch (`span = {1}`),

   (XO5/XO6 `rc-mirror`→`rc-silence`).
3. **Pristine validation** — the unmutated counter run in each setup must reproduce the committed control block
   byte-for-byte (control text minus `ENVELOPE` lines) including exit code. All 7 matched
   (`run-outputs/PRISTINE.<setup>.out`): N rc=1, H rc=2, M rc=1, T rc=1, W rc=0, D rc=1, A rc=1. A baseline
   failure would have made mutants inconclusive; there was none.
4. **22 single-line mutants**, one per enumerated guard family (two per line where the guard has two
   directions), generated by `gen_matrix.py` (each `old` asserted to occur exactly once; every variant
   syntax-checked; per-variant sha256 in `mutants.json`). Each mutant ran in all 7 setups, output diffed against
   the committed control block. Caught-by = the first setup (order N H M T W D A) whose output differs.
5. Every counter invocation ran inside the seat envelope
   `bwrap --dev-bind / / --ro-bind /home/vgpnk/.local/bin /home/vgpnk/.local/bin --tmpfs /run/user/1000 --proc /proc --unshare-pid --die-with-parent`
   (the counter nests its own sandboxes inside; nesting observed working). Campaign receipt: start `17:34:10`,
   end `17:46:17`; `ls -A /home/vgpnk/.local/bin | sha256sum` = `436b361f9d1edc4e` before and after — unchanged.

## Surviving guards with no possible control (documented, not drafted)

- **CM08** (drop `sum(FLOORS.values()) == TOTAL`, L660) and **CM09** (drop `len(MUTANTS) == TOTAL`, L662) are
  **equivalent mutants**: in `good`, `killed == TOTAL` plus the surviving conjuncts imply them. Each mutant
  increments exactly one of killed/survived/invalid/unattributed, so those four counts sum to `len(MUTANTS)`;
  `killed == TOTAL` therefore forces `len(MUTANTS) ≥ TOTAL`, and any extra mutant forces `survived/invalid/
  unattributed ≥ 1` or `killed ≠ TOTAL`, each already rejected by `good`; with `per_tool == [FLOORS, FLOORS]`
  (L661) the FLOORS sum equals the mutant total. No control can distinguish them; the printed count lines still
  expose the state, so the frozen predicate's literal lines are unaffected.
- **CM13** (fingerprint content digest, L338) and **CM19a** (null-difference check, L582) are **unreachable with
  the pinned tools**: `tampered` needs a fixture-tree change between the two fingerprints and `null_detected`
  needs two runs of the same unmodified tool to differ, but tool sandboxes bind the fixture tree read-only (only
  the per-run work/tmp dirs are writable) and both pinned tools are deterministic git-plumbing-only readers. This
  matches the claims file's own framing: these guards are carried "so the counter stays sound for any later tool
  list". CM19b shows the accounting side of the null guard is covered.
