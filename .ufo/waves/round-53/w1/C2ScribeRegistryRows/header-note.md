Each row below describes its instrument at that instrument's own landing tree: the entry, verdict-map and self-test cells say what the script does and what it printed where it was measured, and make no claim about any other tree. The tip-state of every row is declared separately in `plans/round53-tipstate.json`, which holds one entry per row with the argv, the expected exit code, the state (`green` or `red`) and, for a red row, a reason and a verbatim output fragment. The counter `round53-c2` re-executes every declared argv in a clean clone and fails any row whose observed exit differs from its declaration, whose fragment is missing from its output, or which times out, so a declared tip-state that does not hold is caught by execution rather than by reading the cells.
