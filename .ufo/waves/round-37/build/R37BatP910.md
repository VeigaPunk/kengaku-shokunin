### The one harness dependency, disclosed: the lane's own `.gitignore`

P10 re-runs the round-35 probe with `cwd = root`; `spec_from_file_location` byte-compiles the captured grader, so a
`corpus/evidence/round35/tb2-eval/__pycache__/test_outputs.cpython-313.pyc` appears **inside the tree P9 just
checked**. P9 runs before P10 in one invocation, so the first run stays clean and every later run of the same tree
does not. Receipt `receipts/pollute-p9.txt` (a P10 fixture with the ignore rule unstaged and removed, three
consecutive gate runs):

```
-- run 1 (no .gitignore in the tree)   P9 ok untracked=0 first=0
-- run 2 (no .gitignore in the tree)   P9 DEFECT untracked=1 first=corpus/evidence/round35/tb2-eval/__pycache__/test_outputs.cpython-313.pyc
-- run 3 (no .gitignore in the tree)   P9 DEFECT untracked=1 first=corpus/evidence/round35/tb2-eval/__pycache__/test_outputs.cpython-313.pyc
```

The counter runs each fixture several times (reference, renamed copy, null copy, each mutant), so without an ignore
rule the P10 fixtures are non-deterministic — measured, `receipts/noignore-run.txt`:

```
BATTERY fixtures=18 wrong=0 renamed_disagree=2
RENAMED p910-probe-exits-1 DISAGREES
RENAMED p910-receipt-one-byte DISAGREES
MUTANTS total=4 killed=4 survived=0 invalid=0 null_detected=2
```

So the three P10 fixtures copy the lane's own tracked `.gitignore` (`.ufo/interactive-sessions/`,
`__pycache__/`) into the package and stage it. It masks no clause under test (P1–P8 read named files; P9 reads the
ignore rules) and it is a file the project ships; with it, `__pycache__` shows as ignored (`!!`) and P9 reports
`untracked=0`. This is also a limit worth an L1 line: **the frozen gate's own `--rerun` mutates the tree it
certifies**, so a package that does not ignore `__pycache__` fails P9 on its second `--rerun` run.

## Other falsifiers run

1. **Wrong declaration is caught.** Same module with `p910-receipt-deleted` declaring `["P2"]` instead of
   `["P2","P10"]` → `FIXTURE p910-receipt-deleted … declared=P2 observed_defects=P10,P2 WRONG`,
   `BATTERY fixtures=18 wrong=1 renamed_disagree=0`, exit 1 (`receipts/wrongdecl-run.txt`). The declared set is
   load-bearing, not decorative.
2. **Ignore rule is load-bearing.** Removing the three `_ignore_rule(ctx, d)` calls → `renamed_disagree=2`,
   `null_detected=2` (`receipts/noignore-run.txt`); see the section above.
3. **A `--work` inside somebody else's repository still yields a directory that is not a worktree.** The builder
   checks `git -C d rev-parse --show-toplevel` and, if the harness placed `d` inside a repository, writes a
   `.git` pointer to an absent directory, then asserts `git -C d ls-files` fails; if it still answers, the builder
   raises instead of silently producing a wrong fixture. Exercised with
   `--work /fast/scratch/hyaku/kengaku-r37/R37BatP910/fx/lane/.k37work2` (inside my own scratch clone):
   `FIXTURE p910-not-a-git-repo … ok`, `MUTANT M39 P9 killed by=p910-not-a-git-repo`, exit 0
   (`receipts/nested-worktree-run.txt`, `MUTANTS total=1 killed=1`).
4. **Determinism of each fixture in isolation:** each fixture's gate result run twice back to back on the same
   directory is identical — `(1, {P9})`, `(1, {P10,P2})`, `(1, {P10,P1})`, `(1, {P10,P2})`.

## Risks / limits (for the L1)

1. **`uv` dependency.** M42 and M43 need P10 to actually execute the probe (rc available, stdout available). If
   `uv` were missing (or biopython unreachable), `c_rerun` returns at the `OSError` branch *before* the mutated
   lines, so M42/M43 would survive — the fixtures stay correct (`wrong=0`), they just stop killing. Verified
   working on this host; the claims' excluded-branch list already excludes that `OSError` branch from the 55.
2. **The `.gitignore` addition** is the only non-clause file a fixture adds. It is copied from the lane, and
   falsifier 2 above prices it: without it the two P10 fixtures are non-deterministic, not stricter.
3. **Gate observation, not fixable this round (gate frozen):** P10's re-run deposits byte-code inside the tree P9
   certifies, so a second `--rerun` run of an un-ignoring package rejects it on P9 (`receipts/pollute-p9.txt`).
   Any future genuine package fixture that passes `--rerun` needs `__pycache__` ignored, and the gate's P9/P10
   ordering hides this on the first run only.
4. **No claim about the other 51 mutants.** This module is scoped to M39/M41/M42/M43 and its declared sets include
   P2/P10 and P1/P10 pairs for the reason given; the full `BATTERY fixtures=<n> wrong=0 renamed_disagree=0 ...
   killed=55` predicate remains the integration step and is not asserted here.
